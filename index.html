wappy-test Privacy Policy

Effective October 3, 2026.

wappy-test is a private, personal test project that connects a WhatsApp number to an AI assistant. It is not offered to the public. Only phone numbers the developer has explicitly allowed can use it.

What we collect

When an allowed person sends a WhatsApp message to the test number, the project receives the sender's phone number, the message text, and the time it was sent. Nothing else is collected.

How it is used

Message text is sent to an AI model provider (Anthropic) to generate a reply, and the reply is sent back through WhatsApp. Conversation history is stored in a local database on the developer's own computer so the assistant can follow the conversation.

Sharing

We share message text only with Meta (to deliver WhatsApp messages) and Anthropic (to generate replies). We do not sell personal information, show ads, or use messages for any other purpose.

Retention and deletion

Conversation history stays on the developer's computer until it is deleted. To have your data deleted, email the address below and we will remove it.

Security

Access tokens and secrets are kept in a local configuration file and are not published. Incoming requests are checked against Meta's signature, and messages from numbers that are not on the allow list are ignored.
